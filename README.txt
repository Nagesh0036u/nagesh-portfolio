# Nagesh R — Interactive Portfolio

## Run locally
No installation is required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For the best result, run it with VS Code Live Server.

## Included
- Responsive single-page portfolio
- Ice Silver + Deep Aubergine + Marigold visual system
- Animated scroll reveal
- Mobile navigation
- Project category filters
- Interactive project detail modal
- Resume button
- LinkedIn and GitHub links from the supplied resume
- Supplied profile photo

## Easy edits
Main content is in `index.html`.
Colors, spacing and responsive design are in `style.css`.
Interactions are in `script.js`.
